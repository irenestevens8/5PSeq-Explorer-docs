# Optimize User Experience

Here is how to ensure the best possible user experience. 

• Start with metadata table to explore available samples  
• Use filters to narrow down samples before selection  
• Select up to 10-20 samples for most analyses  

The Violin & Ternary Plots are slowest because they are transcript-level.  

Here is how to optimize the Violin & Ternary Plots:

• Limit to 2-6 samples for fastest results  
• Use "Merged" replicate mode when analyzing replicates  
• Be patient: Progress may not be visible during computation  
• Plots render sequentially, not in parallel  

## For Downloads

• Limit downloads to 4 samples to avoid timeouts  
• Please use the Data Freeze (https://doi.org/10.48723/zchv-5x22) for larger downloads.  
• Expect 30-90 seconds for download preparation
